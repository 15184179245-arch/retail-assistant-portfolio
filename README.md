# 零售门店助手｜V3 / V4 项目展示

面向零售门店的个人软件项目。这个仓库是专门整理的面试展示，不是原业务仓库的镜像。

## V3 · 门店操作与设备联调

把查价、库存查询、开单和小票打印放在一条操作流程里。参与 Android 客户端与 Python 后端的接口联调，以及蓝牙和网络打印的功能测试。调试时把接口回复、设备连接、打印结果分开检查。

## V4 · 多端业务协作

在 V3 基础上探索 Web、Android 和服务端协作。参与商品与库存查询、进销存接口对接和业务流程测试。查询时区分“没有匹配结果”“数据还没加载”和“读取失败”，免得店员据此误判。

## 演示怎么用

打开 [demo.html](demo.html)（从 GitHub 查看时请下载该文件后用浏览器打开）。搜索“螺丝”，加入两种规格，修改数量，然后生成预览小票。演示只在页面里计算和预览，不连打印机或业务系统。

演示代码为本次展示重新编写。商品、价格、库存均为虚构；未复制原项目代码、配置、业务数据或历史提交。
